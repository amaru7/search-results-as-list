## 🇬🇧 English

### Summary *(one sentence, shown in search results)*
Always show Thunderbird's global search results as a compact, sortable message list — no more clicking "Show results as list" every single time.

### Description

**Tired of the cluttered search view?**

When you run a global search in Thunderbird, the results first appear in a busy, card-style "faceted" view where only a handful of results fit on screen and every excerpt is cut off. To actually read your results comfortably you have to click **"Show results as list"** — every single time.

**Search Results as List fixes that.** With this add-on installed, every global search opens **directly as a clean, sortable message list**:

- 📋 **See far more results per screen** — tidy rows instead of big cards.
- 🔤 **Full columns** — Subject, Correspondent, Date, Folder — sort by any of them with a click.
- ⚡ **Zero extra clicks** — the list is the default, instantly.
- 🧩 **Same results, same search** — it simply shows Thunderbird's own search results in the list view that's already built in.

**How it works (full transparency)**

Thunderbird already contains a "Show results as list" action. This add-on makes that view the default: when a global-search tab is about to open, it opens the equivalent message-list tab instead, using the exact same underlying search. On Thunderbird 154 and later it also switches on the built-in preference that does this natively.

**Privacy**

This add-on collects nothing, transmits nothing, and contacts no servers. It only changes how existing local search results are displayed. 100% offline.

**Compatibility**

Thunderbird **128, 140, 152 and newer**. (Replacement for the old "Search as list" add-on, which only worked up to Thunderbird 60.)

**Open source**

Licensed under MIT. Contributions and bug reports welcome on GitHub.

## 🇩🇪 Deutsch

### Kurzbeschreibung *(ein Satz, erscheint in der Suche)*
Zeigt Thunderbirds globale Suchergebnisse immer als kompakte, sortierbare Nachrichtenliste an — kein manuelles Klicken auf „Ergebnisse als Liste anzeigen" mehr nötig.

### Beschreibung

**Genervt von der überladenen Suchansicht?**

Bei einer globalen Suche in Thunderbird erscheinen die Ergebnisse zunächst in einer unübersichtlichen Kachelansicht („Facettenansicht"), in der nur wenige Treffer auf den Bildschirm passen und jeder Textausschnitt abgeschnitten ist. Um die Ergebnisse wirklich bequem zu lesen, muss man jedes Mal manuell auf **„Ergebnisse als Liste anzeigen"** klicken.

**Search Results as List löst genau das.** Mit diesem Add-on öffnet sich jede globale Suche **sofort als übersichtliche, sortierbare Nachrichtenliste**:

- 📋 **Deutlich mehr Treffer pro Bildschirm** — kompakte Zeilen statt große Kacheln.
- 🔤 **Vollständige Spalten** — Betreff, Absender, Datum, Ordner — mit einem Klick sortierbar.
- ⚡ **Kein zusätzlicher Klick mehr** — die Liste ist sofort die Standardansicht.
- 🧩 **Gleiche Ergebnisse, gleiche Suche** — es wird lediglich die bereits in Thunderbird eingebaute Listenansicht verwendet.

**So funktioniert es (volle Transparenz)**

Thunderbird bietet bereits die Aktion „Ergebnisse als Liste anzeigen". Dieses Add-on macht diese Ansicht zum Standard: Sobald ein globaler Such-Tab geöffnet werden soll, öffnet das Add-on stattdessen den passenden Listen-Tab — mit derselben zugrunde liegenden Suche. Ab Thunderbird 154 aktiviert es zusätzlich die eingebaute Einstellung, die dasselbe nativ erledigt.

**Datenschutz**

Dieses Add-on sammelt keine Daten, überträgt nichts und kontaktiert keine Server. Es verändert ausschließlich die Darstellung bereits vorhandener lokaler Suchergebnisse. 100 % offline.

**Kompatibilität**

Thunderbird **128, 140, 152 und neuer**. (Ersatz für das alte Add-on „Search as list", das nur bis Thunderbird 60 funktionierte.)
